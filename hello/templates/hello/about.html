ℹ️ About This Application

This is a modern Django web application that serves as a comprehensive ToDo List manager. Built with the latest web technologies to provide an intuitive and visually appealing experience.

⭐ Features

  • Add new tasks to your ToDo list with timestamps
  • View all your current tasks in an organized table format
  • Delete completed tasks with a single click
  • Responsive design that works on all devices
  • Modern, visually appealing interface

⚙️ Technology Stack

  • 🐍 Django 4.1 - Powerful Python web framework
  • 🐍 Python - Backend programming language
  • 💾 SQLite Database - Lightweight database storage
  • 🌐 HTML5 & 🎨 CSS3 - Modern frontend technologies
  • ✨ Modern CSS Design - Beautiful styling and animations

💻 Built with ❤️ using the Django framework
